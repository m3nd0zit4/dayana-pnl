## Antes de empezar: la comprobación

Si marcas cualquiera de estas, **hoy no toca**:

- ☐ El tema es un recuerdo traumático.
- ☐ Es una crisis de esta semana.
- ☐ Mi ancla de recurso no dispara claro en frío.
- ☐ Estoy sola y el tema es grande.

## Elegir bien

| Decisión | La tuya | Control |
|---|---|---|
| El problema | | ¿Intensidad 5-6? Si es 9, elige otro |
| Recurso 1 | | |
| Recurso 2 | | |
| Recurso 3 (opcional) | | |
| ¿El recurso pesa más que el problema? | | Si no, refuerza antes |

## Los siete pasos

| # | Paso | ☐ |
|---|---|---|
| 1 | Problema elegido, concreto y de intensidad media | ☐ |
| 2 | Recurso instalado en una mano, 2-3 estados apilados | ☐ |
| 3 | **Prueba del recurso en frío** — si no dispara, parar aquí | ☐ |
| 4 | Problema anclado en la otra mano, 1-2 repeticiones | ☐ |
| 5 | Las dos a la vez, 15-30 segundos | ☐ |
| 6 | Soltar primero el problema; el recurso, 5 segundos más | ☐ |
| 7 | Probar: pensar en la situación original | ☐ |

**El paso 3 es el que se salta todo el mundo.** Es el que decide si el colapso
funciona o refuerza el problema.

## Después del paso 7

| Cómo se siente ahora la situación | Marca |
|---|---|
| Distinta, más lejos, más neutra | ☐ Funcionó |
| Igual que antes | ☐ El recurso no bastaba |
| Peor | ☐ Parar. Reforzar recursos y no repetir hoy |

## El círculo de excelencia

| # | Paso | ☐ |
|---|---|---|
| 1 | Círculo imaginado en el suelo, con color | ☐ |
| 2 | Fuera del círculo, recordar el mejor estado | ☐ |
| 3 | Cuando sube, entrar caminando | ☐ |
| 4 | Dentro: postura, respiración y frase de ese momento | ☐ |
| 5 | En el pico, salir y romper | ☐ |
| 6 | Repetir 3-5 veces | ☐ |
| 7 | Probar entrando sin preparación | ☐ |
| 8 | Trasladarlo: imaginar el círculo donde hará falta | ☐ |

## Señales para parar en mitad

- Llanto que no cede
- Desconexión o sensación de irrealidad
- El cuerpo se bloquea

**Qué hacer:** soltar las dos anclas, abrir los ojos, mirar alrededor, nombrar
cinco cosas de la habitación en voz alta, beber agua, dejarlo para otro día.

## Autoevaluación

- ☐ Sé por qué el recurso tiene que ser más fuerte que el problema.
- ☐ He hecho la prueba del paso 3 antes de anclar el problema.
- ☐ Sé en qué orden se sueltan las anclas y por qué.
- ☐ Conozco las cuatro situaciones en las que no se hace.
- ☐ Sé qué hacer si algo se desborda.

> Lo último que queda activo es lo que se lleva. Por eso el problema se suelta
> primero.
