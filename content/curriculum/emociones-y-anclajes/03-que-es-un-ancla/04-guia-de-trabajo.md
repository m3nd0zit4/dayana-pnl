## Antes de empezar: elige bien

| Decisión | La tuya |
|---|---|
| **El estado** (uno solo) | |
| **El gesto** — específico, que no hagas por casualidad | |
| **La palabra** (opcional, pero se refuerzan) | |
| **El recuerdo** que te lleva a ese estado | |

**Prueba del gesto:** ¿lo has hecho hoy sin querer? Si sí, cámbialo.

## El protocolo

1. ☐ Siéntate donde no te interrumpan. Diez minutos.
2. ☐ Entra al recuerdo: **qué veías, qué oías, qué sentías y dónde** en el cuerpo.
3. ☐ Deja que suba. No lo fuerces: espéralo.
4. ☐ Justo antes del punto más alto → **el gesto**, 3 a 5 segundos.
5. ☐ Suelta y **rompe el estado**: mira alrededor, cuenta 30 hacia atrás, levántate.
6. ☐ Repite del 2 al 5, **cinco a siete veces**.
7. ☐ Espera **al menos una hora**. Después, en frío: haz el gesto y observa.

## Las cuatro condiciones, para revisar si falla

| Condición | Pregunta de control |
|---|---|
| **Intensidad** | ¿El estado estaba alto de verdad, o solo lo recordaba? |
| **Momento** | ¿Anclé antes del pico, o cuando ya bajaba? |
| **Estímulo único** | ¿Hago ese gesto por casualidad en el día? |
| **Repetición** | ¿Cinco a siete veces, en el mismo punto exacto? |

Si la prueba en frío no dio nada, casi siempre fue la **intensidad**.

## La prueba en frío

| Intento | Cuándo | ¿Apareció algo? (0-10) | Qué apareció |
|---|---|---|---|
| 1 | 1 hora después | | |
| 2 | Al día siguiente | | |
| 3 | A los tres días | | |

Un 3 o 4 el primer día ya es señal. No se busca un interruptor: se busca que
algo se mueva.
