## Antes de interpretar nada

| Revisión | Hoy |
|---|---|
| ¿Cuántas horas dormí? | |
| ¿Cuándo comí por última vez? | |
| ¿Me he movido hoy? | |
| ¿He salido de casa? | |
| ¿Cuánta cafeína llevo? | |

Si tres de las cinco están mal, no analices el estado. Arregla lo básico y
vuelve mañana.

## Registro de una semana

Tres momentos al día. Anota **lo que se ve**, no la interpretación.

| Día | Momento | Qué hacía el cuerpo | A qué atendía | Qué me decía | Nombre del estado |
|---|---|---|---|---|---|
| | mañana | | | | |
| | tarde | | | | |
| | noche | | | | |

Lo que buscas no es un diagnóstico. Es notar que las tres columnas del medio
cambian juntas.
