## Dinero

**Frases que se heredan:**
«El dinero no crece en los árboles» · «La gente rica es deshonesta» · «Nosotros
no somos de esos» · «No se habla de dinero»

**Cómo se nota hoy:**

| Señal | ☐ |
|---|---|
| No subo el precio aunque el trabajo lo valga | ☐ |
| Regalo horas y después me siento usado | ☐ |
| Gasto de golpe cuando llega, como si quemara | ☐ |
| Guardo todo y no disfruto nada | ☐ |
| Me incomoda que me paguen bien | ☐ |

**Tu rastreo:**

| Pregunta | Tu respuesta |
|---|---|
| ¿Qué se decía del dinero en tu casa? | |
| ¿Quién lo manejaba y cómo? | |
| ¿Qué se decía de la gente que tenía? | |
| ¿Qué de eso repites hoy? | |

## Amor

**Frases que se heredan:**
«El amor cuesta» · «Si me conocen de verdad, se van» · «Tengo que ser útil para
que me quieran» · «Amar es aguantar»

**Tu rastreo:**

| Pregunta | Tu respuesta |
|---|---|
| ¿Cómo se querían las personas que te criaron? | |
| ¿Qué había que hacer en tu casa para recibir afecto? | |
| ¿Qué de ese modelo repites sin haberlo elegido? | |
| ¿Qué parte sí quieres conservar? | |

Esa última pregunta importa: no todo lo heredado estorba.

## Valor personal

La ecuación que se instala en la infancia:

```mermaid
flowchart LR
  V["VALGO"] ---|"="| H["lo que hago"]
  class V acento
```

**Las tres señales:**

| Señal | Cómo se nota | ☐ |
|---|---|---|
| No sé recibir | Un elogio incomoda; un regalo obliga | ☐ |
| No pido | Pedir se siente como confesar una carencia | ☐ |
| Me comparo hacia arriba | Nunca con quien está detrás | ☐ |

**Las dos consecuencias:**

1. Los logros nunca alcanzan — lo que sostiene el valor es el **siguiente**.
2. Descansar da culpa — si vales por producir, parar es dejar de valer.

## La pregunta que atraviesa los tres

> **¿Cuánto creo que merezco?**

Trabajar un territorio mueve los otros dos. Y si trabajas solo la superficie
—la tarifa, el límite, la autoestima— sin tocar esta raíz, vuelve.
