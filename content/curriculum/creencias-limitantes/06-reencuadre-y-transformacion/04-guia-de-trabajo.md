## El orden

| # | Herramienta | Qué hace | La pregunta |
|---|---|---|---|
| 1 | **Cuestionar la evidencia** | Agrieta | ¿Alguna vez no fue así? |
| 2 | **Reencuadre de contenido** | Otro significado | ¿Qué más podría significar? |
| 3 | **Reencuadre de contexto** | Quita el juicio | ¿Dónde esto sí serviría? |
| 4 | **Experiencia original** | Cambia la raíz | ¿Qué edad tenía quien concluyó eso? |

---

## 1 · Cuestionar la evidencia

Los tres huecos, en este orden:

| Hueco | La pregunta | Tu respuesta |
|---|---|---|
| **Contraejemplo** | ¿Alguna vez, aunque fuera una, no fue así? | |
| **Fuente** | ¿Quién lo dijo primero? ¿Le daría autoridad hoy? | |
| **Utilidad** | ¿Qué me ha costado creer esto? | |

La tercera suele ser una lista larga. Escríbela entera: mueve más que cualquier
argumento.

## 2 · Reencuadre de contenido

| | Tu respuesta |
|---|---|
| El hecho, en datos (sin interpretación) | |
| Lo que significa para mí ahora | |
| Otro significado posible | |
| Otro más | |

⚠️ Un reencuadre honesto **incluye** lo que dolió. Si suena a «todo pasa por
algo», no es reencuadre: es taparlo.

## 3 · Reencuadre de contexto

| | Tu respuesta |
|---|---|
| «Soy demasiado…» | |
| ¿Dónde eso es exactamente lo que hace falta? | |
| ¿Quién agradece esa característica en mí? | |

**Ejemplos:** detallista → revisando un contrato · impaciente → cuando algo
urge · sensible → acompañando a alguien · terco → sosteniendo lo que otros
abandonaron.

## 4 · La experiencia original

| Pregunta | Tu respuesta |
|---|---|
| ¿Qué edad tenía quien sacó esa conclusión? | |
| ¿Qué no sabía entonces que sí sé ahora? | |
| **Si hoy vieras a otra persona en esa situación, ¿qué le dirías?** | |

La tercera es la que rompe algo. Escríbela como se la dirías de verdad, en voz
alta.

## Tu creencia, después

| | |
|---|---|
| La creencia, como sonaba al empezar | |
| La creencia, después de las cuatro herramientas | |
| ¿Qué se movió? | |

Si no se movió nada, no pasa nada: significa que hay que ir a la raíz con
acompañamiento, o que la frase no era la correcta. Vuelve al módulo 3.

## Lo que falta

Reencuadrar abre la puerta. **No la mantiene abierta.** Sin repetición, el marco
viejo vuelve — porque tiene años de práctica y el nuevo tiene un día.

Eso es el módulo 7.
