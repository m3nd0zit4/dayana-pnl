## Preparación

- **La situación** (concreta, intensidad media): ______________________________
- Tres puntos marcados en el suelo. Un sitio donde nadie te interrumpa.
- Diez o quince minutos.

## 1ª · Desde ti

| Pregunta | Tu respuesta |
|---|---|
| ¿Qué veo desde aquí? | |
| ¿Qué siento, y dónde en el cuerpo? | |
| ¿Qué necesitaba en ese momento? | |
| ¿Qué quería que pasara? | |

☐ **Romper el estado.** Salir de los puntos, mirar alrededor, contar al revés.

## 2ª · Desde el otro

Adopta su postura real. Habla **en primera persona**, como si fueras esa
persona.

| Pregunta | Tu respuesta (en primera persona) |
|---|---|
| «Yo, ______, en esta situación estoy…» | |
| ¿Qué veo desde aquí? | |
| ¿Qué siento? | |
| ¿Qué necesito? | |
| ¿Qué intento conseguir con lo que hago? | |

☐ **Romper otra vez.** Imprescindible.

## 3ª · Desde fuera

De lado, viendo a los dos. Alguien que os quiere a los dos y no toma partido.

| Pregunta | Tu respuesta |
|---|---|
| ¿Qué veo pasar entre estas dos personas? | |
| ¿Qué hace cada una? | |
| ¿Qué necesita cada una? | |
| ¿Qué le diría a la primera? | |
| ¿Qué le diría a la segunda? | |
| **¿Qué es lo que ninguna está viendo?** | |

## Volver

| Pregunta | Tu respuesta |
|---|---|
| ¿Qué me llevo de la segunda? | |
| ¿Qué me llevo de la tercera? | |
| **¿Qué voy a hacer distinto la próxima vez?** | |

Sin la última fila, el ejercicio fue interesante y nada más.

## Control de calidad

- ☐ ¿Me sorprendió algo? *(Si no, no cambié de posición)*
- ☐ ¿Rompí el estado entre posiciones?
- ☐ ¿Hablé en primera persona en la segunda?
- ☐ ¿La tercera me dijo algo distinto de lo que ya pensaba?
- ☐ ¿Salí con una acción concreta?

## Los dos errores

| Error | Cómo se detecta |
|---|---|
| Quedarse en la segunda | Salgo compadeciendo al otro y sin saber qué necesito yo |
| Tercera para tener razón | La tercera confirma exactamente lo que pensaba al empezar |

## Cuándo no hacerlo

- ☐ Hay maltrato → **no se hace**
- ☐ No tengo clara mi primera posición → primero esa
- ☐ La herida está muy reciente → esperar

> Si la tercera posición confirma justo lo que pensabas, no estuviste en la
> tercera. Estuviste en la primera, de pie en otro sitio.
