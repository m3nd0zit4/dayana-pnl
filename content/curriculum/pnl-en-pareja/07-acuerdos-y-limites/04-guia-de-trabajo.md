## El proyecto común

Contestad **por separado** primero, y comparad después.

| Pregunta | Tú | Tu pareja |
|---|---|---|
| ¿Qué queremos que sea esto en cinco años? | | |
| ¿Qué no queremos que pase? | | |
| ¿En qué somos equipo, y en qué no? | | |
| ¿Qué dejamos de hacer que nos hacía bien? | | |
| **¿Qué necesita cada uno para su vida propia?** | | |

La quinta es la más importante y la que menos se hace.

**Las tres preguntas:**

1. ¿Qué funcionó esta semana entre nosotros?
2. ¿Qué necesita cada uno la semana que viene?
3. ¿Hay algún acuerdo que revisar?

**Las reglas:** se empieza por lo que funcionó · no es el sitio para la herida
grande · si sube la temperatura, se para · **se hace aunque no haya nada**.

## El cierre del curso

Las siete piezas:

1. El rapport se construye antes de la conversación difícil.
2. Dos mapas, y un gesto de amor que hay que traducir.
3. Los mismos valores en distinto orden.
4. Niveles distintos: entender, no clasificar.
5. Debajo del conflicto hay una necesidad; lo que salva es reparar.
6. Tres posiciones, y la sorpresa como control de calidad.
7. Acuerdos, límites propios y proyecto dicho en voz alta.

## Cuándo esto no llega

- ☐ Hay violencia → servicio especializado, y no terapia de pareja
- ☐ Hay desprecio sostenido → terapia de pareja
- ☐ Hay una infidelidad reciente → terapia de pareja

> Nadie cambia de pareja por un curso. Lo que cambia es lo que uno hace con lo
> que ya sabía.
