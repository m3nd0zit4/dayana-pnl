## Detectar el canal

**Sin test.** Tres observaciones durante una semana:

| Observación | Tu pareja | Tú |
|---|---|---|
| Verbos que usa cuando algo importa (ver / oír / sentir) | | |
| De qué se queja («ni me miras» / «no me lo dices» / «ni me abrazas») | | |
| **Qué hace cuando quiere demostrar algo** | | |

La tercera fila es la más fiable de las tres.

**Mi conclusión:** su canal parece ______________ · el mío, ______________

## Las dos versiones

Elegid una escena reciente, pequeña.

| | Tu versión | Su versión |
|---|---|---|
| Qué pasó | | |
| Qué sentiste | | |
| Qué creíste que sentía el otro | | |

**Cada uno responde después:** *¿qué de lo que dijo el otro no sabía?*

## Preguntas que abren

| En vez de | Prueba |
|---|---|
| «Eso no fue así» | «¿Cómo lo viviste tú?» |
| «¿Por qué te pusiste así?» | «¿Qué fue lo que más te dolió?» |
| «Yo no dije eso» | «¿Qué entendiste tú de lo que dije?» |
| «Siempre exageras» | «Cuéntame desde tu lado» |

## Señal de alarma

- ☐ Hay ironía habitual
- ☐ Se ponen los ojos en blanco
- ☐ Uno habla del otro como de alguien tonto

Si marcaste alguna: eso es desprecio, y es el predictor de ruptura más fuerte
que existe. No es un problema de canales — es terapia de pareja.

## Autoevaluación

- ☐ Sé qué canal pesa más en cada uno.
- ☐ Sé qué gesto mío no le está llegando.
- ☐ He hecho la pregunta de qué le hace sentir querido/a.
- ☐ Hemos contado la misma escena por turnos, sin interrumpir.
- ☐ Sé distinguir esto de un problema de desprecio.

> Lo que alguien hace para demostrar amor es el mapa de cómo quiere recibirlo.
