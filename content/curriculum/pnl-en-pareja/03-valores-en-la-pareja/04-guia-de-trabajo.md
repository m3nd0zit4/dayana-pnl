## Las cuatro preguntas

Contéstalas cada uno por separado y **después** comparad.

| Pregunta | Tú | Tu pareja |
|---|---|---|
| ¿Qué es lo más importante de una relación? (y «¿qué más?» × 3) | | |
| ¿Qué no soportarías nunca? | | |
| ¿Por qué habéis discutido de verdad este año? | | |
| **¿En qué has cedido y te dejó mal cuerpo semanas después?** | | |

La cuarta es la que más información da.

## La jerarquía

Ordena comparando de a dos. *«Si tuviera que elegir entre ___ y ___, ¿cuál?»*

| Posición | Mi valor | Su valor |
|---|---|---|
| 1 | | |
| 2 | | |
| 3 | | |
| 4 | | |
| 5 | | |

**Lo que casi siempre aparece:** los mismos valores en distinto orden.

## Traducir una discusión

Elegid **una** discusión que se repita.

| Pregunta | Respuesta |
|---|---|
| El tema aparente | |
| Mi valor debajo | |
| Su valor debajo | |
| ¿Son opuestos, o es el mismo valor en distinto orden? | |
| ¿Qué protege cada uno? | |

## El acuerdo

Concreto, verificable, con fecha.

| | |
|---|---|
| **El acuerdo** | |
| **Cómo se comprueba el domingo** | |
| **Qué pasa si uno no lo cumple** | |

Si no se puede comprobar el domingo, no es un acuerdo: es una promesa de
esforzarse más.

## Lo que no se negocia

| Pregunta | Respuesta |
|---|---|
| ¿Hay alguna diferencia de fondo (hijos, dónde vivir, fe)? | |
| ¿Está dicha explícitamente, o se está dejando pasar? | |
| ¿Qué hace falta para hablarla bien? | |

## Autoevaluación

- ☐ Tengo mi jerarquía escrita, ordenada de a dos.
- ☐ Sé qué valor hay debajo de nuestra discusión más repetida.
- ☐ Entiendo que un valor del otro no es una opinión mal informada.
- ☐ Tenemos un acuerdo concreto y verificable, no una promesa.
- ☐ Sé si hay un problema perpetuo, y no me asusta que lo sea.

> Dos tercios de los conflictos de pareja no se resuelven nunca. Las que duran
> aprendieron a hablarlos sin desprecio.
